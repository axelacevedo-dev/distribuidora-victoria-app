# 🎒 App Mochilas Personalizadas

Aplicación móvil enfocada en la personalización de mochilas, permitiendo a los usuarios diseñar su propio producto de forma simple e intuitiva.

## 🚀 Funcionalidad principal

Los usuarios pueden:

- Elegir colores de diferentes partes de la mochila
- Visualizar cambios en tiempo real
- Crear un diseño único personalizado

## 🎯 Objetivo del proyecto

Desarrollar una experiencia interactiva donde cada usuario pueda diseñar su mochila antes de realizar la compra, mejorando la toma de decisión y la personalización del producto.
